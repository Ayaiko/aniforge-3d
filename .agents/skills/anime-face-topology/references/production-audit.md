# Production topology examples and comparison limits

Primary source: Julien Kaspar / Blender Studio, [Planning the Facial Retopology](https://studio.blender.org/training/stylized-character-workflow/5e5407ec8faf011a381510d7/). Reviewed 2026-10-27 through 107 chronological frames at 5-second intervals over 8:51 plus all English captions; not continuous playback. Diagram details were inspected at 01:55, 04:30, 06:40 and 08:40. ASR terminology is imperfect.

Observed: 01:07–01:59 separates feature/muscle edge flow and facial framing; 02:00–02:58 distinguishes landmarks that must move with separate objects; 03:00–04:00 distinguishes permanent and expression-dependent creases; 04:00–05:32 plans articulation with the mid/end arc structure and supporting curvature; 05:32–06:39 connects patches by strategically placed poles, away from heavily deforming creases; 06:49–08:42 explains variation and production compromises, including a corrected draw-over at 08:04. This is not a universal exact-loop-count template.

The head cages use mostly quads with a few triangles, strategic 3/5 poles, inner facial structures, UVs and corrective shape keys. Their raw meshes can contain close-contact overlap candidates and nonplanar quads. Do not call those production defects from a broad-phase BVH overlap or a global warpage cutoff alone; inspect contact regions and evaluated deformation. High-valence fans near moving facial features warrant inspection, but a pole count alone is not a deformation test.

For an A/B comparison, pin the live source and keep cameras, lights, display and subdivision settings identical within each row. Include a shape-preserving repair so topology changes are not mistaken for better proportions. A new quad cage that also changes shape/density is a combined hypothesis: it cannot isolate topology as the cause of a visual gain. Compare exposed face contours to the target plates, not a bald skull to a hair silhouette. New skull/ear guesses remain uncertain.

A new all-quad cage can still lose likeness, produce poor cheek planes, collide with unchanged eyes, or lack useful closure deformation. Label that prototype failed when it does; it neither proves a rebuild is superior nor disproves a carefully fitted manual rebuild. Retain a safe current source while replacing only the topology that the evidence shows needs replacement. Test closure and expressions before calling the cage animation-ready.

Project trial: root-cause-audit-05 found that conservative joins preserved shape but did not fix likeness; an authored analytic quad cage had cleaner counts but worse profile and eye-contact problems. Those failures are implementation-specific. The complete source register, rendered controls, rejected trials and Thai audit report live with that project, rather than being universal skill requirements.
